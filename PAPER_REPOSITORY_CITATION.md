# Repository citation template for the paper

Replace the placeholders after creating the public repository and a versioned release. If a Zenodo DOI is available, use the DOI for the archived release.

## Suggested paper text

> The implementation and reproducibility materials are publicly available at [GitHub repository URL], release [VERSION], archived at [VERSION-SPECIFIC DOI].

## BibTeX software entry

```bibtex
@software{asvspoof2019_pa_explainable_replay_detection,
  author  = {REPLACE WITH THE REPOSITORY AUTHORS},
  title   = {ASVspoof 2019 PA: Explainable Replay-Attack Detection},
  year    = {2026},
  version = {v0.1.0},
  url     = {https://github.com/REPLACE_WITH_USERNAME/asvspoof2019-pa-explainable-replay-detection}
  % doi = {REPLACE WITH THE ZENODO DOI AFTER ARCHIVING}
}
```

Do not include a made-up DOI. Add the `doi` field only after Zenodo has created the record.
